### Overview
Designed and deployed a high-availability SIEM configuration for centralized log collection and threat detection in a production environment.

### Scope
- Deployment of scalable SIEM infrastructure
- Agent installation and configuration across multiple systems

### Result
Implemented structured monitoring with real-time detection capabilities, improved incident visibility, and optimized alert accuracy.

### Overview
Built and integrated code security processes into CI/CD pipelines from scratch for a FinTech environment.

### Scope
- Deployment of open-source SAST solutions
- Software Composition Analysis (dependency scanning)
- Definition and implementation of Quality Gates

### Result
